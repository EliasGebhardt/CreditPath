# Contributing to CreditPath

The goal is a reliable, easy-to-test student prototype rather than a production banking application.

1. Create a branch named `fix/...` or `feature/...`.
2. Keep the demo entirely self-contained and use only fictional company data.
3. Include a short description and screenshot in your Pull Request.
4. Manually check: **Início chart hover → highlighted CreditPath CTA**, **Créditos menu → CreditPath CTA**, **Send message → updated demo recommendation**, **Back to Início**.
5. Never add real bank data, API keys, credentials, transcripts, or private documents.

Ideas worth exploring: improve accessibility, better mobile layout, add clearer scenario assumptions and reduce generic AI response text.
